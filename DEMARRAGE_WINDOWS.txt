SUPERQUEUE - DEMARRAGE SUR WINDOWS

1. Extraire le ZIP dans un dossier de votre choix.
2. Dans VS Code : Fichier > Ouvrir un dossier > SuperQueue (le dossier qui contient app.py).
3. Ouvrir Terminal > Nouveau terminal.
4. Creer environnement : py -3.12 -m venv .venv
5. Installer : .\.venv\Scripts\python.exe -m pip install -r requirements.txt
6. Tester : .\.venv\Scripts\python.exe -m pytest -q
7. Demarrer : .\.venv\Scripts\python.exe -m streamlit run app.py

Ne pas copier les fichiers un par un. Ne pas remplacer votre ancien projet avant verification.
Les ajouts events.py et mean_wait_optimizer.py sont techniques : l interface graphique n est pas encore refaite.
